Precision System

三层精度体系

旧脚本把「标题里出现年份 + 命中关键词」当作唯一判据。研讯把它拆成三层，每一层都可解释、可回放、可调参。

01 / SCORING

加权打分，而不是布尔判断

强词 30 分、中词 12 分、负向词扣分，年份冲突直接惩罚；日期从锚点所在行提取，标题没有年份也能命中。

  • 强词：招生简章 / 专业目录 / 考试大纲 / 改考
  • 年份冲突与陈旧公告降权
  • 每条输出命中理由，可回溯
{{ threshold }}分默认阈值
02 / DEDUP

URL 规范化 + SimHash 近似判重

同一份教育部文件常被多校转载。先用规范化 URL 去精确重复，再用 64 位 SimHash 的汉明距离识别改写标题。

  • 剔除 utm / from / spm 追踪参数
  • index.htm 与目录页归一
  • 跨院校重复只保留最早一条
≤3汉明距离判重
03 / REVIEW

低置信不丢弃，进复核队列

45–59 分的条目不会写入正式清单，而是标记为「待复核」在页面集中呈现，一键收藏或忽略，判断结果反哺阈值。

  • 待复核与正式清单分离
  • 收藏 / 忽略状态持久化
  • 采集失败按类型归因（412 / 超时 / 重置）
0静默丢弃
Deploy

三种方式，十分钟上线

本地用 conda 环境跑，服务器用 Docker，仓库内置 GitHub Actions 做测试与镜像构建。

  • 01
    克隆仓库git clone 后进入项目根目录
  • 02
    准备 conda 环境一条命令创建并安装依赖，Windows 用 .bat 脚本
  • 03
    启动服务默认 127.0.0.1:8000，可用环境变量改端口
  • 04
    接入定时任务cron / 计划任务每天 20:00 自动采集一次
# 1. 克隆
git clone https://github.com/<you>/yanxun.git
cd yanxun

# 2. 创建 conda 环境（已存在则跳过）
conda create -n pyy python=3.11 -y
conda activate pyy
pip install -r requirements.txt

# 3. 启动
python run.py
# -> http://127.0.0.1:8000
